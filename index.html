Cloud Engineer | Software Engineer | AWS & DevOps

I'm Jacob Sidhu, a UK-based Cloud Engineer and Software Engineer with a BSc in Software Engineering from the University of Central Lancashire. I specialise in designing, building and automating secure, scalable and highly available cloud infrastructure.

My technical expertise spans AWS, Terraform, Kubernetes, Docker, CI/CD automation, cloud networking and software development. I enjoy combining cloud infrastructure engineering with application development to deliver reliable, efficient and maintainable solutions.

Through hands-on projects, I've gained practical experience in Infrastructure as Code, distributed systems, container orchestration, cloud security and deployment automation.

Projects

My projects include QuizX, an AWS-based distributed application using Amazon EKS, SQS and Terraform, and DockGen, an AI-powered Dockerfile generator.

Currently building

I'm currently developing CDocX, an AI-assisted healthcare documentation platform that combines cloud technologies, software engineering and intelligent automation to improve healthcare workflows.

Where I'm heading

My long-term ambition is to progress into Cloud and Solutions Architecture, leveraging my software engineering foundation to design resilient, secure and cost-efficient systems that solve real-world challenges.
